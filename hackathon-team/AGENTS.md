# Repository instructions

## Authorship

- Never add the assistant, Codex, ChatGPT, OpenAI, or another AI tool as an author, co-author, contributor, or sign-off identity in this repository's commits, source files, documentation, or generated artifacts.
- Do not add AI attribution trailers such as `Co-authored-by` or generated-by credits. Preserve the user's existing human authorship and Git identity.
- This preference persists for future work in this repository. Do not reintroduce assistant attribution unless the user explicitly changes this instruction.
